How to choose the right installer

Open Settings, then System, then About. Look for System type.

  • If it says 64-bit operating system, download the 64-bit installer.
  • If it says 32-bit operating system, download the 32-bit installer.
  • If a machine is very old or low-spec, the 32-bit installer may be the safer choice.

Before you install

  • Close any running copy of PharmaERP before installing an update.
  • Your data is stored separately from the install folder, so updates keep your records.
  • If Windows shows a publisher warning, confirm the download source before continuing.

Quick install steps

  1. Download the correct setup file.
  2. Run the installer and complete the setup.
  3. Open PharmaERP from the desktop shortcut or Start Menu.

Common questions

Where is my data stored?

PharmaERP stores its database in your Windows AppData folder, separate from the installed app files.

Can I reinstall without losing invoices?

Yes. Reinstalling the app normally does not remove your existing database unless you delete it manually.

Can I share this page for free?

Yes. You can host this site on GitHub Pages, Netlify, or Cloudflare Pages and store the installers on GitHub Releases.
